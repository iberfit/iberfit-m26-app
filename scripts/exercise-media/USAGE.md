Run `autowire.mjs` with a canonical exercise catalog export and a media manifest using schema `iberfit.exercise.media.autowire-input.v2`. Every item must provide the exact canonical `exercise_id` plus a media payload that passes the existing `iberfit.exercise.visual.v1` validator. Names and slugs are never used for matching. The deterministic output is intended for an idempotent Supabase updater; unapproved or invalid media fails closed before publication.
