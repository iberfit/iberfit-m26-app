# IBERFIT M26 · RC12 Design & Functional Assurance

RC12 refuerza el Design System, accesibilidad y cobertura funcional de todos los controles visibles.

- Registro unificado de acciones de shell, sesiones, engagement y verificación.
- Auditoría automática de nombre accesible, tipo de botón, permisos y acciones registradas.
- Estados disabled con aria-disabled.
- Tokens visuales, foco visible, alto contraste, safe areas y layouts móviles.
- Ningún cambio en producción.
