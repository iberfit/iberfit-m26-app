# IBERFIT M26 Recovery Adaptive RC11

Versión local `26.0.0-recovery.11`. No desplegable.

RC11 añade registro dinámico de 52 comandos, builders y servicio Command Bus para check-ins/hábitos/notas privadas, formularios funcionales y motor adaptativo de sesiones basado en adherencia, recuperación y carga histórica. La migración incluida está guardada y termina en rollback hasta disponer del esquema remoto autenticado.
