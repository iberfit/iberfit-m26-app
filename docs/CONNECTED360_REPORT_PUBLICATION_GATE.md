# Connected360 — authorization boundary for official reports

Candidate design, not an installed authorization or an enabled feature. Scope: post-GX350 PR #1477.

## Distinct purposes

- Source access (OS permission + server grant generation/cursor) allows import only.
- Weekly exercise-day and longitudinal trend consents permit only the respective professional reads. Neither can authorize publication.
- Official publication needs an explicit Client decision bound to the exact report draft, recipient Coach assignment and provider, period and evidence digest. No authorization inferred from a prior approval, general terms, consent for another provider, or opening a preview.

## Required vertical contract

Reuse the existing private V49/V56 consent infrastructure where the model is compatible; do not extend an existing purpose to cover publication. If a per-document decision cannot fit its unique key, add a narrowly scoped private append-only authorization ledger, with RLS forced and no direct browser grants. Authoritative server recomputes the exact minimized positive observations from the permitted source generation. Store only reference, digest, provider, subject, report ID and revision/draft hash, purpose, assignment revision, source grant/cursor, decision revision, decision time and withdrawal state. No raw GPS, sensor stream or copied provider secret. Use CAS and idempotent decisions. Never accept arbitrary browser evidence as authority.

Client explicitly sees which document, dates, provider, and aggregate will be published and that an already downloaded PDF cannot be recalled. Consent withdrawal stops future issuance and app-mediated access to affected evidence; it does not erase unrelated history. No reuse of a grant after changed draft, provider, report, reassigned coach, correction, grant-generation change or revoked assignment. Use existing source mutation fence plus existing report/publication client lock, establish lock ordering in QA before installing. Separate publication consent revocation from deleting device data and from withdrawing a complete report. Existing immutable issuance ledger is preserved; invalidated PDF must be blocked by existing authorization RPC and client visibility policy, not deleted as a shortcut.

First delivery permits only date/discipline counts or observed-day continuity, clearly labeled external and partial coverage. No medical diagnosis, automatic change to prescription, workload estimate, inferred inactivity, duplicated training completion or inclusion in the initial IRI. Reassessment evidence remains canonical professional comparisons, not device observations substituted for measurements.
