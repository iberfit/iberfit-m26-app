# IBERFIT M26 · Política científica de baremos

1. El expediente separa identidad de género de `sexForNorms`. Los baremos fisiológicos se aplican únicamente con la variable usada por la fuente científica; nunca se infiere desde el nombre, apariencia o identidad.
2. Edad, sexo para baremos y protocolo exacto son obligatorios antes de puntuar una prueba sensible.
3. No se extrapolan tablas entre sexos, edades, poblaciones ni variantes técnicas.
4. Cuando falta la tabla completa, IBERFIT conserva el valor bruto y marca revisión pendiente; no inventa una categoría.
5. Cada resultado almacena fuente, año/DOI, confianza, población y limitaciones.
6. La puntuación global utiliza únicamente pruebas con referencia válida. El informe muestra cobertura y pruebas pendientes.
7. Los baremos son referencias de desempeño, no diagnósticos médicos.
8. Toda actualización de tablas requiere revisión bibliográfica, prueba de regresión y versionado del motor.
