Ante rollback, poner **solo** `datedTrainingProductionStartsEnabled=false` y conservar `datedTrainingProductionReleased=true`: así las ejecuciones abiertas aún pueden leerse, guardarse, reconciliarse y terminarse. Drenar diarios cifrados e inciertos, comprobar ausencia de `en_curso`, desactivar la UI completa **solo cuando ninguna ejecución la necesite**, y después aplicar disable.sql. El SQL toma un bloqueo transaccional NOWAIT de las ocurrencias **antes** de comprobar `en_curso`: una nueva transición concurrente provoca aborto completo, nunca un permiso revocado a mitad del inicio. 7. Ante inconsistencias, nunca retirar los grants mientras exista una operación iniciada o pendiente. No convertir un error de UI/permiso en resultado guardado ni borrar diarios o fechas.
